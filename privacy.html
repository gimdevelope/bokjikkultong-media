개인정보처리방침

앱 이름: bokjikkultong-yt-cli · 최종 수정: 2026-11-23

본 앱(bokjikkultong-yt-cli)은 복지꿀통 유튜브 채널 운영자가 자신의 채널에 영상·자막·댓글을 올리기 위한 개인용 도구입니다. 일반 사용자를 대상으로 서비스를 제공하지 않으며, 운영자 본인 계정 이외의 사용자 데이터를 수집하지 않습니다.

1. 접근하는 정보

Google 계정으로 OAuth 동의를 받을 때 다음 범위만 요청합니다.

  • https://www.googleapis.com/auth/youtube.upload — 동영상 업로드
  • https://www.googleapis.com/auth/youtube.force-ssl — 자막·댓글 등록 및 관리

이 권한은 운영자 본인의 유튜브 채널에만 사용됩니다.

2. 정보의 저장과 이용

  • OAuth 액세스 토큰과 리프레시 토큰은 운영자의 개인 컴퓨터에 파일 권한 0600으로 저장됩니다.
  • 토큰은 유튜브 API 호출 목적으로만 사용되며, 제3자에게 제공·판매·공유하지 않습니다.
  • 서버로 전송되거나 별도 데이터베이스에 저장되는 개인정보는 없습니다.

3. 보관 기간과 파기

토큰은 저장 파일을 삭제하거나 Google 계정의 보안 → 타사 앱 액세스에서 본 앱의 액세스를 해지하면 즉시 효력이 없어집니다.

4. 제3자 제공

없습니다. 본 앱은 Google YouTube Data API v3 이외의 외부 서비스로 데이터를 전송하지 않습니다. Google API로 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책을 포함한 Google API 서비스 약관을 따릅니다.
